# Company Case Studies

> **Category:** Reference / Case Studies

Deep dives into how real companies adopted and run Kubernetes in production — from the first commit to the architecture, tooling, and lessons learned. Each case follows a consistent template:

- **Who / Scale** — size of the fleet and team.
- **Why K8s** — the problem that triggered the adoption.
- **Journey** — how they migrated (big bang vs. lift-and-shift vs. greenfield).
- **Architecture** — how they structure clusters, identities, and platform services.
- **Tooling** — the ecosystem they built around the cluster.
- **Key Decisions** — the trade-offs that paid off (or didn't).
- **Results** — the measurable outcome.
- **Interview Angle** — a talking point you can cite.
